# redes-wan-Prietp - Módulo Base y Subnetting

Proyecto inicial: estructura base y módulo de subnetting en Python con interfaz Streamlit.

Instrucciones rápidas:
1. Crea un entorno virtual: `python -m venv .venv`
2. Activa el entorno:
   - macOS/Linux: `source .venv/bin/activate`
   - Windows (PowerShell): `.venv\\Scripts\\Activate.ps1`
3. Instala dependencias: `pip install -r requirements.txt`
4. Ejecuta la app: `streamlit run app.py`

No pongas contraseñas ni IPs reales en .env; usa .env.example como plantilla.
